# Alur Pengguna Talenta Nduga

## Pelajar/Mahasiswa
Daftar akun -> pilih jenjang SMA/SMK/S1/S2/S3 -> verifikasi kontak -> masuk -> dasbor -> lengkapi profil -> tambah riwayat pendidikan -> unggah dokumen -> ajukan verifikasi -> peninjauan Operator -> terverifikasi atau perlu perbaikan -> simpan beasiswa -> buat pengingat -> susun riwayat hidup -> persetujuan publikasi -> terbitkan atau cabut publikasi.

## Akun Berkewenangan
Email + kata sandi -> pembatasan percobaan masuk -> verifikasi dua langkah -> pemeriksaan peran -> dasbor sesuai kewenangan -> tindakan -> riwayat audit.

## Operator
Antrean verifikasi -> saring nama/jenjang/status -> buka data pengguna -> periksa profil dan dokumen -> setujui atau minta perbaikan + catatan -> tindakan dicatat pada riwayat audit.

## Administrator
Dasbor -> pengelolaan beasiswa/kegiatan/mitra/pertanyaan umum -> data referensi -> semua pengguna -> pencarian/filter -> aktifkan/nonaktifkan akun -> unduh PDF/Excel -> laporan.

## Administrator Utama
Dashboard tata kelola -> Trafik -> Pelajar & Mahasiswa -> Peran & Izin -> Administrator & Operator -> Kontrol Akun -> Data Referensi/Laporan/Pengaturan -> Log Aktivitas -> Keamanan -> pencabutan sesi bila diperlukan.
